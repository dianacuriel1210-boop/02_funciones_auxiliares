# Evaluación de Funciones Lineales

## Descripción

Este proyecto consiste en desarrollar un programa en **Python** capaz de capturar una función lineal de la forma **y = mx + b** mediante una cadena de texto, por ejemplo `"2x + 3"`.

El programa utiliza expresiones regulares para identificar y extraer los parámetros de la función:

* **m:** pendiente de la recta.
* **b:** ordenada al origen.

Una vez obtenidos estos valores, el programa permite solicitar al usuario una cantidad **n de muestras** y evaluar la función para diferentes valores de `x`.

## Funcionalidades

* Capturar una función lineal mediante texto.
* Identificar automáticamente la pendiente y la ordenada al origen.
* Almacenar los parámetros `m` y `b`.
* Solicitar al usuario la cantidad de muestras.
* Evaluar la función utilizando la fórmula `y = mx + b`.
* Mostrar los resultados de cada muestra.
* Utilizar funciones para mantener el código organizado y modular.
* Aplicar buenas prácticas de programación y el estándar **PEP 8**.
